About This Tool

How It Works

This tool uses pre-compiled tap drill charts to provide accurate drill sizes for standard thread specifications. No calculations - just reliable chart data.

Thread Percentages

  • 75% Thread (Soft): Aluminum, brass, plastics - easier tapping, adequate strength
  • 50% Thread (Hard): Steel, stainless steel, cast iron - reduces tap breakage risk

Thread Unit M/Is

  • Imperial: UNC (Coarse) and UNF (Fine) UNEF (Extra Fine) threads measured in inches
  • Metric: ISO metric threads with sizes in millimeters
